PROJECT_EVOLUTION

این پوشه مسئول مدیریت تکامل معماری پروژه TANDIL است.

تمام ایده‌هایی که هنوز وارد قانون اساسی نشده‌اند ولی برای آینده پروژه ضروری هستند، در این پوشه ثبت می‌شوند.

هر Evolution دارای شناسه مستقل است و شامل:

- مسئله
- دلیل ایجاد
- معماری پیشنهادی
- وابستگی‌ها
- زمان اجرا
- وضعیت
- Snapshot موردنیاز

پس از پیاده‌سازی، Evolution به completed منتقل شده و Snapshot مربوطه تولید می‌شود.

در آینده Evolution Engine این فرآیند را به‌صورت خودکار مدیریت خواهد کرد.
