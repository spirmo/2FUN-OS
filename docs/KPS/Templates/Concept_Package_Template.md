# Concept Package (بسته کانسپت)

> نسخه: 1.0
> وضعیت: DRAFT

---

# 1. Canonical Name (نام استاندارد کانسپت)

نام اصلی و یکتای کانسپت را وارد کنید.

مثال:

- عدالت
- انرژی
- جرم
- اعتماد

راهنما:

در این قسمت فقط نام کانسپت نوشته می‌شود.

از نوشتن توضیح، تعریف یا جمله خودداری کنید.

---

# 2. Short Description (توضیح کوتاه)

در دو یا سه جمله، مفهوم کلی این کانسپت را توضیح دهید.

این بخش برای معرفی سریع کانسپت است و جایگزین تعریف علمی نیست.

---

# 3. Definitions (تعاریف)

## Definition 1 (تعریف شماره ۱)

### Definition Text (متن تعریف)

تعریف کامل را وارد کنید.

---

### Definition Type (نوع تعریف)

مثال:

- علمی
- فلسفی
- حقوقی
- فنی

---

### Language (زبان)

مثال:

- فارسی
- English
- العربية

---

### Source (منبع)

نام کتاب، مقاله، استاندارد یا مرجع را وارد کنید.

---

# 4. Evidence (شواهد)

## Evidence 1 (شاهد شماره ۱)

### Evidence Text (متن شاهد)

متن دقیق شاهد را وارد کنید.

---

### Evidence Source (منبع شاهد)

کتاب، مقاله یا سند

---

### Page / Section (صفحه / بخش)

مثال:

صفحه ۱۲۵

بند ۳-۲

---

# 5. Aliases (نام‌های جایگزین)

تمام نام‌هایی را که این کانسپت با آن‌ها شناخته می‌شود وارد کنید.

مثال:

- داد
- انصاف

---

# 6. Relationships (روابط)

## Relationship 1 (رابطه شماره ۱)

### Related Concept (کانسپت مرتبط)

نام کانسپت مقصد

---

### Relationship Type (نوع رابطه)

مثال:

- نوعی از
- جزءِ
- علت
- معلول
- وابسته به

---

### Supporting Evidence (شاهد رابطه)

اگر این رابطه مستند است، شاهد آن را وارد کنید.

---

# 7. Metadata (فراداده)

در صورت نیاز ویژگی‌های اضافی را وارد کنید.

|            |               |
