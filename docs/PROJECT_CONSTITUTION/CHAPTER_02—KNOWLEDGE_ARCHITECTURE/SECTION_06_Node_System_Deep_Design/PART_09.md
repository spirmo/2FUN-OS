CHAPTER_02 — KNOWLEDGE ARCHITECTURE

SECTION_06 — Node System Deep Design

PART_09 — Node و مسیر یادگیری (Learning Path)

در معماری TANDIL، هیچ Node به‌صورت کاملاً مستقل عمل نمی‌کند.

ارزش واقعی Node زمانی آشکار می‌شود که در کنار سایر Nodeها قرار گیرد و بخشی از یک مسیر یادگیری (Learning Path) را تشکیل دهد.

Node واحد اجرایی است؛ اما Learning Path حاصل ارتباط هدفمند میان چندین Node است.

---

Learning Path چیست؟

Learning Path یک توالی منطقی از Nodeهاست که برای رساندن کاربر از یک وضعیت شناختی به وضعیت شناختی دیگر طراحی می‌شود.

هدف مسیر یادگیری تنها انتقال دانش نیست.

هدف آن، ایجاد رشد تدریجی، پایدار و قابل ارزیابی در کاربر است.

---

نقش Node در مسیر

هر Node تنها مسئول مأموریت خود است.

اما در کنار سایر Nodeها، بخشی از یک زنجیره بزرگ‌تر را تشکیل می‌دهد.

به همین دلیل، هر Node باید:

- نقطه ورود مشخص داشته باشد.
- نقطه خروج مشخص داشته باشد.
- جایگاه خود را در مسیر بشناسد.
- برای انتقال به Node بعدی آماده باشد.

---

انواع ارتباط میان Nodeها

ارتباط میان Nodeها می‌تواند به شکل‌های مختلفی باشد:

- خطی (Linear): هر Node تنها به Node بعدی متصل است.
- شرطی (Conditional): انتخاب Node بعدی به نتیجه اجرای Node فعلی بستگی دارد.
- انشعابی (Branching): یک Node می‌تواند چند مسیر مختلف ایجاد کند.
- همگرا (Merging): چند مسیر مختلف می‌توانند به یک Node مشترک برسند.

این ساختارها امکان طراحی مسیرهای ساده و پیچیده را فراهم می‌کنند.

---

اصل استقلال

هیچ Node نباید منطق کل مسیر را در خود نگهداری کند.

هر Node فقط مسئول اجرای مأموریت خود است.

منطق مسیر در ارتباط میان Nodeها شکل می‌گیرد، نه درون یک Node منفرد.

---

شخصی‌سازی مسیر

در TANDIL، دو کاربر ممکن است از Nodeهای یکسان استفاده کنند، اما ترتیب عبور آن‌ها متفاوت باشد.

این تفاوت می‌تواند بر اساس:

- سطح دانش
- نتایج ارزیابی
- اهداف کاربر
- الگوهای رفتاری
- یا قوانین سیستم

ایجاد شود.

بنابراین، مسیر یادگیری می‌تواند پویا و متناسب با هر کاربر باشد، در حالی که Nodeها ثابت باقی می‌مانند.

---

مزایای معماری

تفکیک Node از Learning Path باعث می‌شود:

- Nodeها قابلیت استفاده مجدد داشته باشند.
- مسیرهای جدید بدون تولید Nodeهای تکراری ساخته شوند.
- نگهداری و توسعه سیستم ساده‌تر شود.
- شخصی‌سازی مسیرها بدون تغییر در ساختار دانش امکان‌پذیر باشد.

---

اصل معماری

بر اساس قانون اساسی TANDIL:

Node کوچک‌ترین واحد اجرایی مسیر است.

Learning Path ساختاری است که از اتصال هدفمند Nodeها شکل می‌گیرد.

این اصل تضمین می‌کند که مسیرهای یادگیری بتوانند بدون وابستگی به ساختار داخلی Nodeها، توسعه یافته و برای نیازهای مختلف کاربران بازطراحی شوند.
