CHAPTER_02 — KNOWLEDGE ARCHITECTURE

SECTION_06 — Node System Deep Design

PART_05 — مرز میان Node و Concept

در معماری TANDIL، Node و Concept در دو لایه کاملاً متفاوت از سیستم قرار دارند.

Concept در لایه حقیقت قرار دارد، در حالی که Node در لایه اجرای دانش قرار می‌گیرد.

به همین دلیل، هیچ رابطه مالکیت یا وابستگی مستقیم میان این دو موجودیت وجود ندارد.

---

Concept چیست؟

Concept بنیادی‌ترین موجودیت معماری دانش است.

Concept:

- حقیقت را تعریف می‌کند.
- دارای هویت معنایی مستقل است.
- خارج از مسیرهای آموزشی نیز وجود دارد.
- مستقل از کاربران، فناوری و نحوه ارائه دانش است.

Concept به این پرسش پاسخ می‌دهد:

«چه چیزی حقیقت دارد؟»

---

Node چیست؟

Node یک موجودیت اجرایی است.

Node تعیین می‌کند:

- چه دانشی فعال شود.
- در چه مرحله‌ای فعال شود.
- با چه ترتیبی ارائه شود.
- و چه شرایطی برای عبور به مرحله بعد وجود داشته باشد.

Node به این پرسش پاسخ می‌دهد:

«دانش چگونه اجرا شود؟»

---

تفاوت بنیادی

Concept = حقیقت

Node = فرآیند اجرای دانش

Concept درباره «وجود» است.

Node درباره «جریان» است.

---

رابطه غیرمستقیم

Node هرگز مستقیماً با Concept کار نمی‌کند.

ارتباط همواره از طریق لایه‌های میانی برقرار می‌شود:

Concept → Knowledge Unit → Knowledge Block → Node

این زنجیره یکی از مهم‌ترین اصول معماری TANDIL است، زیرا از وابستگی مستقیم لایه اجرا به لایه حقیقت جلوگیری می‌کند.

---

دلیل این جداسازی

اگر Node مستقیماً به Concept وابسته باشد:

- هر تغییر در مسیرهای آموزشی می‌تواند بر ساختار حقیقت اثر بگذارد.
- منطق اجرا با منطق معنا در هم آمیخته می‌شود.
- نگهداری و توسعه سیستم دشوار خواهد شد.

اما با جداسازی این دو:

- حقیقت پایدار باقی می‌ماند.
- مسیرهای یادگیری آزادانه تغییر می‌کنند.
- و ساختار دانش انعطاف‌پذیر می‌ماند.

---

مثال

Concept:

«عدالت»

ممکن است در ده‌ها Knowledge Unit و Knowledge Block مختلف حضور داشته باشد.

Nodeهای متفاوتی نیز می‌توانند از آن استفاده کنند:

- مسیر آموزش حقوق
- مسیر اخلاق حرفه‌ای
- مسیر مدیریت
- مسیر حکمرانی
- مسیر تربیت کودک

در همه این موارد، Concept تغییر نمی‌کند.

فقط مسیر اجرای دانش متفاوت است.

---

اصل عدم مالکیت

Node مالک هیچ Conceptی نیست.

Concept نیز وابسته به هیچ Nodeی نیست.

Node تنها نتیجه سازمان‌دهی دانش مرتبط با Conceptها را اجرا می‌کند.

---

اصل معماری

بر اساس قانون اساسی TANDIL:

Concept حقیقت را حفظ می‌کند.

Node مسیر تجربه و استفاده از دانش مرتبط با آن حقیقت را مدیریت می‌کند.

این تفکیک، استقلال کامل میان «هستی حقیقت» و «نحوه تجربه حقیقت» را تضمین می‌کند و یکی از ارکان اساسی پایداری معماری TANDIL به‌شمار می‌آید.
