CHAPTER_02 — KNOWLEDGE ARCHITECTURE

SECTION_06 — Node System Deep Design

PART_04 — مرز میان Node و Domain

در معماری TANDIL، Node و Domain دو موجودیت مستقل هستند که هر یک وظیفه متفاوتی در شبکه دانش بر عهده دارند.

Domain مرزهای موضوعی دانش را مشخص می‌کند، در حالی که Node مسیر حرکت و اجرای دانش را مدیریت می‌کند.

این دو ممکن است با یکدیگر ارتباط داشته باشند، اما هیچ‌کدام جایگزین دیگری نیستند.

---

Domain چیست؟

Domain نماینده یک حوزه یا قلمرو دانشی است.

وظیفه Domain مشخص کردن این است که:

- یک موضوع در کدام حوزه قرار می‌گیرد.
- مرزهای مفهومی آن حوزه چیست.
- چه Conceptها و ساختارهای دانشی در آن قلمرو استفاده می‌شوند.

Domain به این پرسش پاسخ می‌دهد:

«این دانش متعلق به کدام حوزه است؟»

---

Node چیست؟

Node یک واحد اجرایی در مسیر یادگیری یا تحلیل است.

وظیفه Node مشخص کردن این است که:

- دانش در چه مرحله‌ای ارائه شود.
- ترتیب ارائه چگونه باشد.
- شرایط ورود و خروج از هر مرحله چیست.

Node به این پرسش پاسخ می‌دهد:

«این دانش چگونه و در چه زمانی ارائه شود؟»

---

تفاوت بنیادی

Domain = قلمرو دانش

Node = مسیر اجرای دانش

Domain درباره مکان مفهومی دانش است.

Node درباره حرکت در میان دانش است.

---

استقلال از Domain

Node نباید به یک Domain خاص وابسته باشد.

یک Node می‌تواند:

- تنها از یک Domain استفاده کند.
- از چندین Domain به‌صورت هم‌زمان استفاده کند.
- یا در مسیرهایی قرار گیرد که میان چند حوزه دانشی حرکت می‌کنند.

این ویژگی، انعطاف‌پذیری معماری TANDIL را افزایش می‌دهد.

---

مثال

فرض کنید یک Node با عنوان:

«تصمیم‌گیری در شرایط بحرانی»

طراحی شده است.

این Node ممکن است از Knowledge Blockهایی استفاده کند که به Domainهای مختلف تعلق دارند:

- روان‌شناسی
- مدیریت
- اقتصاد
- اخلاق
- ارتباطات

در این مثال:

Node فقط مسیر یادگیری را مدیریت می‌کند.

وابستگی موضوعی هر بخش همچنان توسط Domainها تعیین می‌شود.

---

اصل عدم مالکیت

Domain مالک Node نیست.

Node نیز مالک Domain نیست.

Node تنها در صورت نیاز از دانش موجود در Domainهای مختلف استفاده می‌کند.

---

اصل استفاده مجدد

یک Node می‌تواند در چندین Domain مورد استفاده قرار گیرد.

همچنین یک Domain می‌تواند شامل تعداد زیادی Node با اهداف متفاوت باشد.

این استقلال باعث می‌شود:

- مسیرهای یادگیری به حوزه خاصی محدود نشوند.
- توسعه سیستم ساده‌تر شود.
- و دانش میان حوزه‌های مختلف به‌صورت کنترل‌شده جریان پیدا کند.

---

اصل معماری

بر اساس قانون اساسی TANDIL:

Domain مرزهای دانش را تعیین می‌کند.

Node مسیر حرکت در میان دانش را تعیین می‌کند.

این تفکیک تضمین می‌کند که «قلمرو دانش» و «فرآیند یادگیری» دو لایه مستقل باقی بمانند و هر کدام بدون ایجاد وابستگی ساختاری، قابلیت توسعه و تکامل داشته باشند.
