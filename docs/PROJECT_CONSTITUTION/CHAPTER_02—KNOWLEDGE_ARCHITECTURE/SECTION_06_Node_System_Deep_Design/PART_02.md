CHAPTER_02 — KNOWLEDGE ARCHITECTURE

SECTION_06 — Node System Deep Design

PART_02 — تعریف رسمی Node

در معماری TANDIL، Node یک موجودیت اجرایی-ساختاری است که وظیفه آن تبدیل دانش ایستا به تجربه قابل هدایت است.

Node نقطه‌ای است که در آن دانش، ساختار و هدف آموزشی به یک «واحد قابل اجرا در مسیر یادگیری» تبدیل می‌شوند.

---

تعریف رسمی Node

«Node یک واحد ساختاری در معماری TANDIL است که با هدف تعریف ترتیب، جریان و فعال‌سازی Knowledge Blockها و Knowledge Unitها در یک مسیر مشخص طراحی شده و نقش آن تبدیل دانش سازمان‌یافته به تجربه اجرایی قابل هدایت است.»

---

ویژگی‌های بنیادین Node

هر Node دارای ویژگی‌های زیر است:

- دارای هدف مشخص در مسیر یادگیری یا تحلیل
- شامل یک یا چند Knowledge Block
- دارای ترتیب اجرایی (Execution Order)
- وابسته به Context یا وضعیت کاربر
- قابل استفاده در مسیرهای مختلف (Reusable Path Component)

---

Node به‌عنوان واحد اجرایی

Node برخلاف Knowledge Block، صرفاً یک ساختار دانشی نیست.

Node یک واحد اجرایی (Execution Unit) در سیستم است.

به این معنا که:

- تصمیم می‌گیرد چه دانش‌هایی فعال شوند
- ترتیب نمایش دانش را مشخص می‌کند
- تجربه یادگیری را شکل می‌دهد

---

نقش Node در تجربه یادگیری

Node تعیین می‌کند:

- کاربر چه چیزی را ابتدا می‌بیند
- چه مفاهیمی بعد از آن فعال می‌شوند
- چگونه پیچیدگی به‌صورت تدریجی افزایش یابد
- و چگونه فهم به‌صورت مرحله‌ای شکل بگیرد

---

تفاوت Node با ساختارهای دانشی

Node خودش دانش تولید نمی‌کند.

بلکه:

- Knowledge Block را اجرا می‌کند
- Knowledge Unit را فعال می‌کند
- و Concept را در قالب تجربه ارائه می‌دهد

---

جایگاه در معماری

Node در لایه میانی-اجرایی قرار دارد:

- Concept → حقیقت
- Knowledge Unit → دانش
- Knowledge Block → ساختار دانش
- Node → اجرای دانش
- Domain → مرز کاربرد دانش

---

اصل استقلال

Node به‌صورت مستقل از Knowledge Block و Domain طراحی می‌شود.

به این معنا که:

- یک Node می‌تواند از چندین Knowledge Block استفاده کند
- یک Knowledge Block می‌تواند در چندین Node استفاده شود
- هیچ‌کدام مالک دیگری نیستند

---

مثال کاربردی

Node: «درک تفکر نقاد»

اجرا در Node:

1. فعال‌سازی Knowledge Block مبانی تفکر نقاد
2. سپس فعال‌سازی Knowledge Block خطاهای شناختی
3. سپس فعال‌سازی Knowledge Block تحلیل استدلال
4. سپس فعال‌سازی سناریوی عملی

این ترتیب توسط Node کنترل می‌شود، نه توسط Knowledge Block.

---

اصل معماری

بر اساس قانون اساسی TANDIL:

Node مسئول اجرای دانش در قالب تجربه زمانی و ترتیبی است.

این اصل Node را به لایه‌ای تبدیل می‌کند که دانش را از حالت «ساختار ایستا» به «فرآیند یادگیری زنده» تبدیل می‌کند.
