CHAPTER_02 — KNOWLEDGE ARCHITECTURE

SECTION_06 — Node System Deep Design

PART_03 — مرز میان Node و Knowledge Block

در معماری TANDIL، Node و Knowledge Block به‌طور مستقیم با یکدیگر همکاری می‌کنند، اما هرگز نقش یکدیگر را ایفا نمی‌کنند.

Knowledge Block ساختار دانش را تعریف می‌کند.

Node نحوه اجرای آن ساختار را مدیریت می‌کند.

---

Knowledge Block چیست؟

Knowledge Block مجموعه‌ای سازمان‌یافته از Knowledge Unitهاست که برای پوشش یک موضوع، مهارت یا مسئله طراحی شده است.

Knowledge Block به این پرسش پاسخ می‌دهد:

«چه دانشی باید در کنار هم قرار گیرد؟»

---

Node چیست؟

Node واحد اجرایی مسیر یادگیری یا تحلیل است.

Node مشخص می‌کند:

- کدام Knowledge Block فعال شود.
- در چه زمانی فعال شود.
- با چه ترتیبی فعال شود.
- و تحت چه شرایطی به Node بعدی منتقل شود.

Node به این پرسش پاسخ می‌دهد:

«این دانش چه زمانی و چگونه اجرا شود؟»

---

تفاوت بنیادی

Knowledge Block = ساختار دانش

Node = جریان اجرای دانش

Knowledge Block درباره محتوا است.

Node درباره فرآیند است.

---

استقلال عملکردی

Knowledge Block مستقل از مسیرهای یادگیری وجود دارد.

اما Node بدون محتوایی برای اجرا، ارزش عملی ندارد.

در نتیجه:

- Knowledge Block بدون Node قابل تعریف است.
- Node بدون Knowledge Block، معمولاً مأموریتی برای انجام ندارد.

---

رابطه میان آن‌ها

یک Node می‌تواند:

- یک Knowledge Block را اجرا کند.
- چندین Knowledge Block را به‌ترتیب اجرا کند.
- یا بر اساس شرایط مختلف، میان چند Knowledge Block انتخاب کند.

در مقابل، یک Knowledge Block می‌تواند در ده‌ها Node مختلف مورد استفاده قرار گیرد.

---

مثال

Knowledge Block:

«مبانی تفکر نقاد»

ممکن است در Nodeهای زیر استفاده شود:

- شروع دوره تفکر نقاد
- آموزش تصمیم‌گیری
- تحلیل اخبار
- آموزش مدیران
- ارزیابی توانایی استدلال

Knowledge Block ثابت است.

Nodeها متفاوت هستند.

---

اصل عدم مالکیت

هیچ Node مالک Knowledge Block نیست.

Node تنها از طریق ارجاع، Knowledge Block مورد نیاز خود را فراخوانی می‌کند.

این اصل باعث می‌شود:

- تغییر در یک Knowledge Block به‌صورت خودکار در تمام Nodeهای استفاده‌کننده اعمال شود.
- مسیرهای جدید بدون تولید محتوای تکراری ساخته شوند.

---

اصل معماری

بر اساس قانون اساسی TANDIL:

Knowledge Block دانش را سازمان‌دهی می‌کند.

Node دانش سازمان‌دهی‌شده را به جریان یادگیری و تجربه اجرایی تبدیل می‌کند.

این تفکیک یکی از مهم‌ترین اصول معماری TANDIL است، زیرا مانع از ترکیب «ساختار دانش» با «منطق اجرای دانش» می‌شود و هر لایه را مستقل، قابل نگهداری و قابل توسعه نگه می‌دارد.
