CHAPTER_02 — KNOWLEDGE ARCHITECTURE

SECTION_04 — تعریف Knowledge Unit در معماری دانش

PART_07 — رابطه Knowledge Unit با Node

در معماری TANDIL، Knowledge Unit و Node دو موجودیت با نقش‌های کاملاً متفاوت هستند که در کنار یکدیگر فرآیند یادگیری، رشد و تحلیل را شکل می‌دهند.

Knowledge Unit دانش را حمل می‌کند.

Node مسیر استفاده از آن دانش را سازمان‌دهی می‌کند.

---

Node چیست؟

Node یک واحد ساختاری در مسیر رشد، یادگیری یا تحلیل است.

هر Node مجموعه‌ای از Conceptها، Knowledge Unitها، سؤال‌ها و قوانین مرتبط را در یک زمینه مشخص گردآوری می‌کند.

Node به این پرسش پاسخ می‌دهد:

«کاربر در این مرحله از مسیر رشد، به چه دانشی نیاز دارد؟»

---

Knowledge Unit چیست؟

Knowledge Unit کوچک‌ترین واحد مستقل انتقال دانش است.

هر Knowledge Unit محتوای معتبر درباره یک یا چند Concept را در اختیار سامانه قرار می‌دهد.

Knowledge Unit به این پرسش پاسخ می‌دهد:

«چه دانشی باید منتقل شود؟»

---

تفاوت بنیادی

Node ساختار مسیر را تعیین می‌کند.

Knowledge Unit محتوای مسیر را تأمین می‌کند.

Node درباره سازمان‌دهی است.

Knowledge Unit درباره انتقال دانش است.

---

رابطه میان آن‌ها

هر Node می‌تواند شامل تعداد زیادی Knowledge Unit باشد.

هر Knowledge Unit نیز می‌تواند هم‌زمان در چندین Node مورد استفاده قرار گیرد.

برای مثال:

یک Knowledge Unit درباره «تصمیم‌گیری مبتنی بر شواهد» ممکن است در Nodeهای زیر حضور داشته باشد:

- تفکر نقاد
- مدیریت
- حل مسئله
- رهبری
- تصمیم‌گیری اقتصادی

در تمام این موارد، محتوای Knowledge Unit یکسان باقی می‌ماند و تنها زمینه استفاده از آن تغییر می‌کند.

---

اصل عدم مالکیت

هیچ Node مالک Knowledge Unit نیست.

Node تنها از Knowledge Unitهای مورد نیاز خود استفاده می‌کند.

اگر یک Node حذف شود، Knowledge Unit همچنان در سایر Nodeها قابل استفاده خواهد بود.

اگر Node جدیدی ایجاد شود، می‌تواند از Knowledge Unitهای موجود استفاده کند، بدون آنکه نسخه جدیدی از آن‌ها ایجاد شود.

---

اصل استفاده مجدد

Knowledge Unit با هدف استفاده مجدد طراحی شده است.

هرچه تعداد Nodeهای سامانه افزایش یابد، ارزش این اصل بیشتر آشکار می‌شود؛ زیرا دانش یک‌بار تولید می‌شود، اما می‌تواند در مسیرهای رشد مختلف مورد استفاده قرار گیرد.

این رویکرد از:

- تکرار محتوا،
- ناسازگاری علمی،
- و افزایش هزینه نگهداری

جلوگیری می‌کند.

---

اصل معماری

بر اساس قانون اساسی TANDIL:

Knowledge Unit دانش را حمل می‌کند.

Node مسیر استفاده از دانش را سازمان‌دهی می‌کند.

این اصل تضمین می‌کند که توسعه مسیرهای رشد، بدون نیاز به بازتولید دانش انجام شود و شبکه دانشی پروژه، در عین گسترش، انسجام و یکپارچگی خود را حفظ کند.
