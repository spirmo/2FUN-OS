CHAPTER_02 — KNOWLEDGE ARCHITECTURE

SECTION_05 — تعریف Knowledge Block در معماری دانش

PART_06 — مرز میان Knowledge Block و Node

در معماری TANDIL، Knowledge Block و Node دو موجودیت با نقش‌های متفاوت هستند که در دو لایه جداگانه از سیستم قرار دارند.

Node یک واحد هدایت و مسیرسازی است، در حالی که Knowledge Block یک واحد سازمان‌دهی دانش محسوب می‌شود.

---

Node چیست؟

Node ساختاری است که مسیر حرکت دانش، یادگیری یا تحلیل را تعیین می‌کند.

Node مشخص می‌کند:

- کاربر در چه مرحله‌ای قرار دارد
- چه مفاهیمی باید در هر مرحله فعال شوند
- ترتیب ارائه دانش چگونه باشد
- و مسیر رشد چگونه طراحی شود

Node به این پرسش پاسخ می‌دهد:

«دانش در چه مسیری و در چه مرحله‌ای باید ارائه شود؟»

---

Knowledge Block چیست؟

Knowledge Block مجموعه‌ای سازمان‌یافته از Knowledge Unitهاست که یک موضوع یا مهارت را به‌صورت یک بسته دانشی منسجم ارائه می‌دهد.

Knowledge Block تعیین نمی‌کند دانش در چه مرحله‌ای استفاده شود؛ بلکه مشخص می‌کند:

«این دانش چگونه باید کنار هم قرار گیرد تا قابل فهم باشد؟»

---

تفاوت بنیادی

Node = مسیر و جریان یادگیری
Knowledge Block = ساختار محتوای دانش

Node درباره «ترتیب و جریان» است.
Knowledge Block درباره «محتوا و سازمان‌دهی» است.

---

استقلال از Node

Knowledge Block وابسته به Node نیست.

یک Knowledge Block می‌تواند:

- در چندین Node مختلف استفاده شود
- یا در هیچ Node خاصی محدود نشود
- و به‌صورت مستقل در سیستم وجود داشته باشد

در مقابل، Node می‌تواند از Knowledge Blockهای مختلف برای ساخت مسیرهای یادگیری استفاده کند.

---

رابطه میان آن‌ها

Node از Knowledge Blockها برای ساخت مسیر یادگیری استفاده می‌کند.

Knowledge Block از Knowledge Unitها برای ساخت محتوای دانشی استفاده می‌کند.

بنابراین رابطه به شکل زیر است:

Node → استفاده از Knowledge Block
Knowledge Block → استفاده از Knowledge Unit

---

اصل عدم مالکیت

Node مالک Knowledge Block نیست.

Knowledge Block نیز مالک Node نیست.

هر دو تنها از طریق ارجاع در شبکه دانش به یکدیگر متصل می‌شوند.

---

مثال

Node: «مسیر یادگیری تفکر نقاد»

Knowledge Blockها:

- بلوک مبانی تفکر نقاد
- بلوک خطاهای شناختی
- بلوک تحلیل استدلال
- بلوک سناریوهای واقعی

هر Node می‌تواند از همین Knowledge Blockها در مسیرهای متفاوت استفاده کند، بدون اینکه ساختار داخلی آن‌ها تغییر کند.

---

اصل استفاده مجدد

Knowledge Blockها می‌توانند در چندین Node مختلف استفاده شوند.

این اصل باعث می‌شود:

- مسیرهای یادگیری بدون تکرار محتوا ساخته شوند
- طراحی آموزشی انعطاف‌پذیر باشد
- و نگهداری سیستم ساده‌تر شود

---

اصل معماری

بر اساس قانون اساسی TANDIL:

Node مسیر حرکت دانش را تعیین می‌کند.
Knowledge Block ساختار دانش در هر نقطه از مسیر را ارائه می‌دهد.

این تفکیک باعث می‌شود که «مسیر یادگیری» و «ساختار دانش» از هم جدا بمانند و شبکه دانشی بتواند بدون پیچیدگی و تداخل توسعه پیدا کند.
