CHAPTER_06 — HUMAN MODEL

SECTION_05 — Interaction Profile

PART_01 — Interaction Profile چیست؟

انسان تنها با دانستن، یاد گرفتن و استدلال کردن شناخته نمی‌شود.

نحوه تعامل او با محیط نیز بخشی از شناخت اوست.

در پروژه TANDIL، بخش مهمی از این تعامل، ارتباط انسان با خود سیستم است.

سیستم باید بتواند تشخیص دهد:

- کاربر چگونه با سیستم تعامل می‌کند؟
- الگوی حضور او چگونه است؟
- میزان مشارکت او چقدر است؟
- رفتار او در طول زمان چه روندی دارد؟

برای پاسخ به این پرسش‌ها، Human Model دارای بخشی مستقل به نام Interaction Profile است.

---

اصل بنیادین

Interaction Profile رفتار انسان را ثبت می‌کند.

نه شخصیت او را.

---

تعریف Interaction Profile

«Interaction Profile بخشی از Human Model است که الگوهای تعامل کاربر با سامانه TANDIL را به‌صورت پویا و بر پایه رفتارهای واقعی ثبت و تحلیل می‌کند، بدون آنکه درباره شخصیت یا نیت کاربر قضاوت کند.»

---

هدف این طراحی

این مفهوم برای پاسخ به این پرسش طراحی شده است:

«سیستم چگونه نحوه تعامل یک انسان با خود سامانه را می‌شناسد؟»

---

چرا Interaction Profile ضروری است؟

دو کاربر ممکن است:

- دانش یکسانی داشته باشند.
- شیوه یادگیری مشابهی داشته باشند.
- کیفیت استدلال نزدیکی داشته باشند.

اما:

- یکی به‌صورت منظم با سیستم تعامل کند.
- دیگری فقط به‌صورت پراکنده وارد سامانه شود.

این تفاوت، مستقیماً بر کیفیت آموزش و رشد اثر می‌گذارد.

---

موضوع Interaction Profile

Interaction Profile درباره موارد زیر است:

- الگوی حضور
- استمرار تعامل
- میزان مشارکت
- کیفیت تعامل با سیستم
- روند فعالیت

---

تفاوت با Learning Profile

Learning Profile بررسی می‌کند:

کاربر چگونه یاد می‌گیرد.

Interaction Profile بررسی می‌کند:

کاربر چگونه با سیستم تعامل می‌کند.

---

تفاوت با Reasoning Profile

Reasoning Profile کیفیت اندیشیدن را تحلیل می‌کند.

Interaction Profile کیفیت و الگوی تعامل را.

---

ارتباط با Human Model

Interaction Profile یکی از اجزای مستقل Human Model است.

در کنار:

- Concept Profile
- Learning Profile
- Reasoning Profile

تصویر کامل‌تری از وضعیت انسان ایجاد می‌کند.

---

مزایای این طراحی

این معماری باعث می‌شود:

- کیفیت تعاملات قابل تحلیل باشد.
- آموزش با میزان مشارکت کاربر هماهنگ شود.
- روند حضور کاربر قابل بررسی باشد.
- سیستم بتواند تصمیم‌های بهتری اتخاذ کند.

---

نگاه فلسفی

در TANDIL:

شناخت انسان تنها از پاسخ‌های او حاصل نمی‌شود.

شیوه حضور و تعامل او نیز بخشی از مسیر رشد اوست.

Interaction Profile برای ثبت همین بُعد طراحی شده است.

---

اصل معماری

بر اساس قانون اساسی TANDIL:

Interaction Profile باید به‌عنوان بخشی مستقل از Human Model، الگوهای تعامل واقعی کاربر با سامانه TANDIL را ثبت و تحلیل کند و این اطلاعات باید بدون قضاوت درباره شخصیت یا نیت کاربر، تنها بر پایه رفتارهای مشاهده‌شده و داده‌های معتبر نگهداری شوند.

این اصل تضمین می‌کند که Human Model علاوه بر شناخت دانش، یادگیری و استدلال، بتواند کیفیت و روند تعامل انسان با سامانه را نیز به‌صورت دقیق و معماری‌شده مدل‌سازی کند.
