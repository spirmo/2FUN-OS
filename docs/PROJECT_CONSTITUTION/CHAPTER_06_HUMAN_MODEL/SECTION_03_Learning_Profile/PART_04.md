CHAPTER_06 — HUMAN MODEL

SECTION_03 — Learning Profile

PART_04 — پویایی Learning Profile (Dynamic Learning Profile)

Learning Profile نباید یک توصیف دائمی از شیوه یادگیری انسان باشد.

همان‌گونه که دانش انسان تغییر می‌کند،

شیوه یادگیری او نیز در طول زمان می‌تواند تکامل پیدا کند.

بنابراین، Learning Profile نیز باید یک موجودیت پویا باشد.

---

اصل بنیادین

شیوه یادگیری ثابت نیست.

Learning Profile نیز نباید ثابت باشد.

---

تعریف Dynamic Learning Profile

«Dynamic Learning Profile مدلی است که به‌صورت مستمر و تدریجی، بر اساس رفتارهای واقعی یادگیری کاربر، تغییر کرده و آخرین الگوهای معتبر یادگیری او را نمایش می‌دهد.»

---

هدف این طراحی

این مفهوم برای پاسخ به این پرسش طراحی شده است:

«اگر شیوه یادگیری یک انسان در طول زمان تغییر کند، سیستم چگونه باید با آن سازگار شود؟»

---

چرا پویایی ضروری است؟

ممکن است یک کاربر:

- در ابتدای کار به مرورهای متعدد نیاز داشته باشد.
- اما پس از مدتی بتواند مفاهیم را با سرعت بیشتری تثبیت کند.

اگر Learning Profile ثابت بماند،

سیستم همچنان آموزش‌های قدیمی را ادامه خواهد داد.

---

عوامل ایجاد تغییر

Learning Profile می‌تواند بر اثر عوامل زیر تغییر کند:

- افزایش تجربه
- استمرار یادگیری
- تغییر کیفیت تعاملات
- بهبود یا کاهش پایداری دانش
- تغییر در روند یادگیری Conceptها

---

تغییر تدریجی

تغییر در Learning Profile باید آرام و تدریجی باشد.

هیچ Interaction منفرد نباید به‌تنهایی باعث تغییر اساسی در شیوه یادگیری ثبت‌شده شود.

سیستم باید روند کلی را بررسی کند.

---

تفاوت با Concept Profile

Concept Profile وضعیت کاربر نسبت به یک Concept را تغییر می‌دهد.

Learning Profile تغییر در فرآیند یادگیری را ثبت می‌کند.

در نتیجه:

این دو مکمل یکدیگر هستند،

اما مسئولیت‌های متفاوتی دارند.

---

نقش Question Engine

Question Engine باید همواره از آخرین نسخه معتبر Learning Profile استفاده کند.

اگر Learning Profile تغییر کند،

روش تولید Question نیز می‌تواند تغییر کند.

---

نقش Versioning

هر تغییر معنادار در Learning Profile نیز باید نسخه‌بندی شود.

این موضوع امکان تحلیل تکامل شیوه یادگیری را فراهم می‌کند.

---

مزایای این طراحی

این معماری باعث می‌شود:

- آموزش با تغییرات واقعی انسان هماهنگ بماند.
- سیستم از روش‌های قدیمی استفاده نکند.
- کیفیت یادگیری افزایش یابد.
- شناخت سیستم همواره به‌روز باشد.

---

نگاه فلسفی

در TANDIL:

یادگیری، خود یک مهارت است.

و همان‌گونه که دانش رشد می‌کند،

مهارت یادگیری نیز رشد می‌کند.

Learning Profile باید این رشد را منعکس کند.

---

اصل معماری

بر اساس قانون اساسی TANDIL:

Learning Profile باید به‌عنوان یک مدل پویا طراحی شود که بر پایه رفتارهای واقعی یادگیری، به‌صورت تدریجی تکامل یابد و تغییرات آن تنها بر اساس روندهای معتبر و شواهد مستمر اعمال شوند، نه بر پایه تعاملات منفرد یا نوسان‌های کوتاه‌مدت.

این اصل تضمین می‌کند که شناخت سیستم از شیوه یادگیری انسان، همواره بازتابی از وضعیت واقعی و فعلی او باشد و آموزش بتواند همراه با رشد انسان تکامل پیدا کند.
