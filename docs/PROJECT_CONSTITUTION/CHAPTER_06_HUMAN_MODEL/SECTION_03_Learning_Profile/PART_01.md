CHAPTER_06 — HUMAN MODEL

SECTION_03 — Learning Profile

PART_01 — Learning Profile چیست؟

دانستن اینکه یک کاربر نسبت به یک Concept در چه وضعیتی قرار دارد، تنها بخشی از شناخت انسان است.

سیستم همچنین باید بداند:

این انسان چگونه یاد می‌گیرد؟

دو کاربر ممکن است در یک سطح از دانش باشند،

اما روش یادگیری آن‌ها کاملاً متفاوت باشد.

به همین دلیل، Human Model دارای بخشی مستقل به نام Learning Profile است.

---

اصل بنیادین

Concept Profile می‌گوید:

کاربر چه چیزی را یاد گرفته است.

Learning Profile می‌گوید:

کاربر چگونه یاد می‌گیرد.

---

تعریف Learning Profile

«Learning Profile بخشی از Human Model است که الگوهای یادگیری، ویژگی‌های آموزشی و روند کسب دانش یک کاربر را به‌صورت پویا و مستقل از Conceptهای خاص نگهداری می‌کند.»

---

هدف این طراحی

این مفهوم برای پاسخ به این پرسش طراحی شده است:

«سیستم چگونه سبک و ویژگی‌های یادگیری هر انسان را می‌شناسد؟»

---

چرا Learning Profile ضروری است؟

اگر سیستم فقط میزان دانش را بداند،

نمی‌تواند تشخیص دهد:

- بهترین روش آموزش چیست.
- سرعت مناسب آموزش چقدر است.
- چه زمانی باید مرور انجام شود.
- چه نوع Question برای کاربر مناسب‌تر است.

Learning Profile این اطلاعات را فراهم می‌کند.

---

تفاوت با Concept Profile

Concept Profile بر یک Concept خاص تمرکز دارد.

برای مثال:

«وضعیت کاربر نسبت به Concept «عدالت».»

اما Learning Profile به رفتار کلی یادگیری نگاه می‌کند.

برای مثال:

«آیا این کاربر با مثال بهتر یاد می‌گیرد؟»

---

موضوع Learning Profile

Learning Profile درباره موضوعات آموزشی است،

نه درباره حقیقت.

این بخش بررسی می‌کند:

- روند یادگیری
- شیوه یادگیری
- پایداری یادگیری
- واکنش به آموزش

---

ارتباط با Question Engine

Question Engine از Learning Profile استفاده می‌کند تا:

- نوع مناسب Question را انتخاب کند.
- فاصله زمانی سؤال‌ها را تنظیم کند.
- سطح دشواری را کنترل کند.
- روش آموزش را شخصی‌سازی نماید.

---

ارتباط با Human Model

Learning Profile یکی از اجزای Human Model است.

در کنار:

- Concept Profile
- Reasoning Profile
- Interaction Profile
- Growth Profile

تصویر کامل‌تری از انسان ایجاد می‌کند.

---

مزایای این طراحی

این معماری باعث می‌شود:

- آموزش کاملاً شخصی‌سازی شود.
- کیفیت یادگیری افزایش یابد.
- تعاملات طبیعی‌تر شوند.
- سیستم از رفتار واقعی یادگیرنده آگاه باشد.

---

نگاه فلسفی

در TANDIL:

هدف تنها انتقال دانش نیست.

هدف، کمک به رشد انسان با روشی است که بیشترین سازگاری را با شیوه یادگیری او داشته باشد.

Learning Profile ابزار تحقق همین هدف است.

---

اصل معماری

بر اساس قانون اساسی TANDIL:

Learning Profile باید به‌عنوان بخشی مستقل از Human Model، الگوهای یادگیری، ویژگی‌های آموزشی و روند کسب دانش هر کاربر را نگهداری کند و این اطلاعات باید برای شخصی‌سازی تعاملات آموزشی، بدون وابستگی به Conceptهای خاص، در اختیار موتورهای تصمیم‌گیری قرار گیرد.

این اصل تضمین می‌کند که TANDIL علاوه بر شناخت میزان دانش انسان، شیوه یادگیری او را نیز بشناسد و آموزش را متناسب با آن تنظیم کند.
