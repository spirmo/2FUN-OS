CHAPTER_06 — HUMAN MODEL

SECTION_03 — Learning Profile

PART_05 — استقلال Learning Profile از Conceptها

Learning Profile و Concept Profile ارتباط نزدیکی با یکدیگر دارند، اما نباید با یکدیگر اشتباه گرفته شوند.

Concept Profile نشان می‌دهد:

کاربر نسبت به چه چیزی رشد کرده است.

Learning Profile نشان می‌دهد:

کاربر چگونه رشد می‌کند.

به همین دلیل، این دو باید به‌صورت مستقل نگهداری شوند.

---

اصل بنیادین

موضوع یادگیری با فرآیند یادگیری متفاوت است.

---

تعریف استقلال

«استقلال Learning Profile به این معناست که اطلاعات مربوط به شیوه و الگوهای یادگیری کاربر، مستقل از وضعیت او نسبت به Conceptهای خاص نگهداری شوند، هرچند هر دو از تعاملات مشترک تغذیه می‌شوند.»

---

هدف این طراحی

این مفهوم برای پاسخ به این پرسش طراحی شده است:

«چرا Learning Profile نباید در داخل Concept Profile قرار گیرد؟»

---

تفاوت دو مسئولیت

Concept Profile

پرسش زیر را پاسخ می‌دهد:

«وضعیت کاربر نسبت به Concept «عدالت» چگونه است؟»

---

Learning Profile

پرسش زیر را پاسخ می‌دهد:

«این کاربر به‌طور کلی چگونه یاد می‌گیرد؟»

---

مثال

فرض کنید کاربری:

- مفهوم «صداقت» را سریع یاد می‌گیرد.
- مفهوم «عدالت» را با تمرین بیشتر می‌آموزد.

Concept Profile این تفاوت را ثبت می‌کند.

اما اگر در مجموع مشخص شود که:

کاربر معمولاً با تکرار بهتر یاد می‌گیرد،

این اطلاعات در Learning Profile ذخیره می‌شوند.

---

جلوگیری از وابستگی

اگر Learning Profile وابسته به یک Concept خاص باشد،

با تغییر وضعیت همان Concept،

کل مدل یادگیری دچار نوسان خواهد شد.

اما در معماری TANDIL،

Learning Profile از مجموعه تعاملات استفاده می‌کند،

نه از یک Concept منفرد.

---

ارتباط میان دو بخش

Learning Profile می‌تواند از اطلاعات Concept Profile استفاده کند.

اما مالک آن نیست.

به همین ترتیب،

Concept Profile نیز از Learning Profile تبعیت نمی‌کند.

ارتباط میان آن‌ها از طریق Human Model برقرار می‌شود.

---

مزایای این طراحی

این معماری باعث می‌شود:

- تحلیل شیوه یادگیری پایدارتر باشد.
- تغییرات یک Concept کل مدل یادگیری را مختل نکند.
- توسعه Human Model ساده‌تر شود.
- مسئولیت هر بخش کاملاً مشخص باشد.

---

نگاه فلسفی

در TANDIL:

دانستن «چه چیزی» و دانستن «چگونه» دو نوع شناخت متفاوت هستند.

شناخت موضوع،

جایگزین شناخت فرآیند نمی‌شود.

Learning Profile نیز بازتاب همین تمایز است.

---

اصل معماری

بر اساس قانون اساسی TANDIL:

Learning Profile باید به‌صورت کامل از Concept Profileها مستقل نگهداری شود و تنها الگوها و ویژگی‌های عمومی فرآیند یادگیری کاربر را نمایش دهد. هرگونه ارتباط میان این دو بخش باید در سطح Human Model و از طریق تحلیل معماری برقرار گردد، نه از طریق وابستگی مستقیم داده‌ها.

این اصل تضمین می‌کند که Human Model بتواند هم موضوع یادگیری و هم فرآیند یادگیری را به‌صورت مستقل تحلیل کند و از اختلاط این دو حوزه جلوگیری شود.
