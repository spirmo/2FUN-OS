CHAPTER_06 — HUMAN MODEL

SECTION_04 — Reasoning Profile

PART_01 — Reasoning Profile چیست؟

دانستن اینکه یک انسان چه چیزی را می‌داند و چگونه یاد می‌گیرد، برای شناخت کامل او کافی نیست.

سیستم باید بتواند تشخیص دهد:

این انسان چگونه فکر می‌کند و چگونه استدلال می‌کند؟

دو کاربر ممکن است:

- دانش یکسانی داشته باشند.
- شیوه یادگیری مشابهی داشته باشند.

اما کیفیت استدلال آن‌ها کاملاً متفاوت باشد.

به همین دلیل، Human Model دارای بخشی مستقل به نام Reasoning Profile است.

---

اصل بنیادین

دانش با استدلال یکسان نیست.

Reasoning Profile میزان دانش را اندازه‌گیری نمی‌کند.

Reasoning Profile کیفیت استدلال را مدل می‌کند.

---

تعریف Reasoning Profile

«Reasoning Profile بخشی از Human Model است که الگوها، کیفیت و ویژگی‌های فرآیند استدلال کاربر را بر پایه تعاملات واقعی و تحلیل پاسخ‌ها نگهداری می‌کند، بدون آنکه محتوای دانش او را جایگزین کند.»

---

هدف این طراحی

این مفهوم برای پاسخ به این پرسش طراحی شده است:

«سیستم چگونه کیفیت استدلال یک انسان را می‌شناسد؟»

---

چرا Reasoning Profile لازم است؟

ممکن است دو کاربر پاسخ صحیح یکسانی ارائه دهند.

اما:

- یکی با استدلال منطقی به پاسخ رسیده باشد.
- دیگری پاسخ را حفظ کرده باشد.

Concept Profile این تفاوت را نشان نمی‌دهد.

Learning Profile نیز آن را ثبت نمی‌کند.

Reasoning Profile برای تحلیل همین تفاوت طراحی شده است.

---

موضوع Reasoning Profile

Reasoning Profile درباره موارد زیر است:

- نحوه استدلال
- کیفیت تحلیل
- انسجام منطقی
- توانایی ارتباط میان Conceptها
- کیفیت نتیجه‌گیری

---

تفاوت با Concept Profile

Concept Profile پاسخ می‌دهد:

«کاربر نسبت به این Concept در چه وضعیتی قرار دارد؟»

Reasoning Profile پاسخ می‌دهد:

«کاربر هنگام فکر کردن چگونه از Conceptها استفاده می‌کند؟»

---

تفاوت با Learning Profile

Learning Profile فرآیند یادگیری را بررسی می‌کند.

Reasoning Profile فرآیند استدلال را بررسی می‌کند.

این دو مستقل اما مکمل هستند.

---

ارتباط با Answer Analysis Engine

بخش زیادی از اطلاعات موردنیاز Reasoning Profile از تحلیل پاسخ‌های کاربر استخراج می‌شود.

اما خروجی نهایی تنها پس از تبدیل به Signalهای استاندارد وارد Human Model خواهد شد.

---

مزایای این طراحی

این معماری باعث می‌شود:

- کیفیت تفکر قابل تحلیل باشد.
- آموزش فراتر از حفظ کردن حرکت کند.
- رشد قدرت تحلیل قابل اندازه‌گیری شود.
- سیستم بتواند استدلال‌های پیچیده‌تر را درک کند.

---

نگاه فلسفی

در TANDIL:

دانستن حقیقت ارزشمند است.

اما توانایی استدلال درباره حقیقت،

ارزشمندتر است.

Reasoning Profile برای شناخت همین توانایی طراحی شده است.

---

اصل معماری

بر اساس قانون اساسی TANDIL:

Reasoning Profile باید به‌عنوان بخشی مستقل از Human Model، کیفیت، ساختار و الگوهای استدلال کاربر را بر پایه تعاملات واقعی و Signalهای استاندارد نگهداری کند و این اطلاعات باید مستقل از میزان دانش و شیوه یادگیری کاربر تحلیل شوند.

این اصل تضمین می‌کند که TANDIL علاوه بر شناخت آنچه انسان می‌داند و چگونه می‌آموزد، بتواند کیفیت اندیشیدن او را نیز به‌صورت معماری‌شده و قابل توضیح مدل‌سازی کند.
