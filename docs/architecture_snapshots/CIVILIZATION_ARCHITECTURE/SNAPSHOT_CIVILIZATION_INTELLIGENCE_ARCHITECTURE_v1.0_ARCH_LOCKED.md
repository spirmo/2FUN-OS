1. VISION

هدف اصلی TOOFAN ایجاد یک موتور تحلیل تمدنی انسان است.

هدف سیستم:

- شناخت انسان
- ثبت مسیر زندگی انسان
- استخراج الگوهای رفتاری
- استخراج الگوهای شناختی
- استخراج الگوهای اجتماعی
- استخراج الگوهای معنوی
- ساخت همزاد دیجیتال
- ساخت کتاب زندگی
- ساخت گراف تمدنی دانش انسانی

سیستم قرار نیست:

- به جای انسان تصمیم بگیرد
- انسان را هدایت اجباری کند
- نقش مشاور تحمیلی داشته باشد
- مسیر زندگی را برای کاربر تعیین کند

سیستم فقط مشاهده، ثبت، تحلیل و مدل‌سازی می‌کند.
