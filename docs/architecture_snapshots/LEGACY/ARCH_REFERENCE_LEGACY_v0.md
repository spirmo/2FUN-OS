## 1. Project Concept
This snapshot defines the unified architecture for user identity and member structure in the 2FUN / TANDIL system.

## 2. Identity Model Layers

### Layer 1: Authentication Identity (Visible to User)
- First name
- Last name
- Phone number
- Email
- Location (country/city)
- Authentication level
- Verification status

### Layer 2: System Visible Profile (Public System Data)
- Rank
- Colony rank
- Governance score
- Reputation
- Activity history
- Achievements
- Participation level

### Layer 3: Hidden Governance Data (Restricted Access)
Accessible only by:
- Founders
- Governance Council

Includes:
- Financial intelligence level
- Technical skill level
- Analytical capability level
- Risk level
- Leadership potential
- Trust index
- Influence index
- Stability index
- Adaptation index

## 3. Governance Structure

### Core Entities:
- Founders (permanent root authority)
- Governance Council (elected/advanced users)

### Rule:
Users can evolve into Governance Council through system progression.

## 4. System Principle

- Identity is multi-layered
- Not all data is user-visible
- System governance has privileged access layers
- User progression is hierarchical

## 5. Version Lock

This architecture is locked for current system phase:
- No structural removal allowed
- Only extension in future versions permitted
