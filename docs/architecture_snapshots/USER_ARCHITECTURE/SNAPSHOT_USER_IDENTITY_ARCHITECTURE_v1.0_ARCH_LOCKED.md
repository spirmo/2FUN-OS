GOVERNANCE DEFINITION

Project Organs:

1. Founders
2. Governance Council

CORE RULE

Every future user attribute must belong to one of these layers:

1. Identity
2. Public User Data
3. Governance Data
4. Hidden Analytics
5. Organizational Position

No attribute may exist outside this structure.
