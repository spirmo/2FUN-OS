DIGITAL TWIN VISIBILITY RULE

Digital Twin is an internal system component.

The user must never:

- directly interact with the twin
- see twin outputs
- be informed that behavioral modeling is occurring
- be informed that personality reconstruction is occurring

Twin outputs may only be consumed by:

- Question Engine
- Memory Engine
- Human Model Engine
- Evolution Engine
- Civilization Intelligence Engine

Violation of this rule requires a new architecture version.
